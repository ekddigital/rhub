CERTIFICATE ID FORMAT EXPLAINED
---------------------------------
Example ID:  JICF-2026-EAS-0001-LM

  JICF  → Organization prefix  (Jinan International Christian Fellowship)
  2026  → Year the certificate was issued
  EAS   → Type code — "EAS" for Easter (matched from template name)
  0001  → Sequence number (auto-incremented, 4 digits, zero-padded)
  LM    → Random 2-character suffix for uniqueness (changes every issue)

DOWNLOADING FOR MANUAL SIGNING
---------------------------------
When Pastor Joseph needs to sign the certificate by hand:

  1. Go to Admin Panel → Certificates → Issued Certificates
  2. Find the certificate and click the Download button
  3. In the Download dialog, tick: "For manual signing"
     → This hides ONLY the electronic signature image, leaving
       the signature line, pastor name, and title visible —
       so the pastor knows where and as whom to sign.
  4. Select PDF (recommended for printing) and click Download.
  5. Print and hand to the pastor for signing.

When you want the fully digital version (with electronic signature):
  → Do NOT tick "For manual signing" — the signature image appears.
